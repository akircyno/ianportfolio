# Ian Aquino Portfolio

Portfolio website monorepo with a Next.js App Router frontend and a Node.js/TypeScript backend.

## Structure

- `frontend` - Next.js, TypeScript, Tailwind CSS
- `backend` - Node.js, TypeScript

## Getting Started

Install dependencies in each app:

```bash
cd frontend
npm install

cd backend
npm install
```

Run the frontend:

```bash
cd frontend
npm run dev
```

Run the backend:

```bash
cd backend
npm run dev
```
